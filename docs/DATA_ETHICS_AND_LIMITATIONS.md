# Data Ethics, Confidentiality, and Model Limitations

- Use only publicly licensed data in the repository.
- Keep unpublished academic and employer data outside public version control.
- Record dataset accession, source, license, and download date.
- Separate training, validation, and test data.
- Select parameters on validation data, not on the final test set.
- Report failure cases and uncertainty; do not show only successful examples.
- Treat segmentation as a measurement method that requires biological and technical validation.
- Avoid claiming AI expertise beyond the demonstrated scope: applied bioimage analysis, model use, limited fine-tuning, and workflow validation.
